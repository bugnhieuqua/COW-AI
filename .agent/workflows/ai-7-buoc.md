# Quy trình 7 bước AI

Thực hiện lần lượt, mỗi bước xong phải dừng chờ người dùng duyệt:

1. Dùng skill `phan-tich-yeu-cau` -> tạo docs/01-yeu-cau.md
2. Dùng skill `thiet-ke-kien-truc` -> tạo docs/02-kien-truc.md và docs/03-ke-hoach-module.md
3. Với từng module trong kế hoạch, lặp lại:
   a. Dùng skill `lap-trinh-tung-module`
   b. Dùng skill `unit-test` -> cập nhật docs/04-bao-cao-test.md
4. Dùng skill `review-kiem-thu` -> tạo docs/05-bao-cao-review.md
5. Dùng skill `kiem-tra-bao-mat` -> tạo docs/06-bao-cao-bao-mat.md
6. Dùng skill `dong-goi-ban-giao` -> hoàn thiện README và docs/07-tong-ket.md

Bắt đầu bằng cách hỏi người dùng mô tả ý tưởng/dự án.
